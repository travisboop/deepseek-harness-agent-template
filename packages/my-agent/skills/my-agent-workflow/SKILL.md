name: my-agent-workflow
description: 查询合成记录、核对计算并形成可追溯答复；开发时替换为本专业方法。
---

用户需要查询或汇总 alpha、beta 示例资料时使用本 Skill。

1. 确认用户要核对的记录和计算目标。
2. 使用 `my_agent_lookup` 读取对应记录。保留返回的 `source` 和 `synthetic`。
3. 根据实际数量、单价计算各项金额，再汇总数量和金额。币种不同时分别汇总。
4. 回答中列出记录、计算过程和来源，说明使用了合成数据。
5. 缺少必要输入或工具失败时说明缺口。直接会话可向用户追问；受委派时把缺口交回 Host。

示例中的 alpha、beta 只用于演示和测试。替换成业务 Skill 时写清触发条件、输入、工具、判断步骤、完成条件和异常处理，并同步业务测试。
